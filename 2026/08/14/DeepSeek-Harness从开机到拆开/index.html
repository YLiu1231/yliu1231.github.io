DeepSeek Harness：从开机到拆开

发表于 2026-08-14 分类于 Self-Learning
一份基于 DeepSeek Harness v0.1 开发者预览版的实测手册，覆盖安装、权限、运行模式、成本、插件、PTC、自我改造与事故复盘。

《DeepSeek Harness：从开机到拆开》记录了 DeepSeek Harness v0.1 开发者预览版发布时的产品状态。它既说明如何把 Coding Agent 跑起来，也进一步拆解会话事件流、工具系统、插件机制和自我改造能力。

这本书讲什么

这不是一份只复述官方说明的安装教程。书中材料来自官方仓库与文档、683 篇设计笔记，以及作者在本机完成的一手测试。内容从“十分钟完成第一项任务”开始，逐步进入权限边界、四种运行模式、会话事件、成本统计、动态工具、PTC 模式、Skill、MCP 与插件冲突。

全书特别关注产品在开发者预览阶段的真实状态：哪些行为已经跑通，哪些文档与实现存在差异，哪些接口可能发生破坏性变化。读者既能看到功能，也能理解 Agent Harness 的运行边界和失败方式。

内容结构

  • 进门：完成首次运行，理解工作区、权限、四种模式，以及从 Claude Code 迁移时可以复用的内容。
  • 主线：分析会话事件流、单次任务成本、动态工具、PTC 模式和长任务执行。
  • 地基：梳理 Skill、MCP、插件之间的关系，并复盘已经出现的问题。
  • 收束：观察一个大量使用 AI 编写的代码库，并讨论 DeepSeek Harness 的技术选择与代价。

阅读时建议关注

  1. 本地运行不等于数据不出本机：进程、文件、模型请求和遥测需要分别判断。
  2. 权限模型不只是一组开关：沙箱、审批策略、工作区范围与网络访问共同决定风险边界。
  3. 成本需要从真实事件流中核算：模型调用、缓存、工具执行和长任务循环都会影响最终费用。
  4. 可扩展性也会引入冲突：当 Skill、MCP 和多个插件同时管理工具或文件时，需要明确优先级与失败提示。
