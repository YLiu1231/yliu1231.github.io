梁文锋访谈：DeepSeek 的 AGI 战略

发表于 2026-07-23 分类于 Tech
从战略克制、Coding Agent、开源低价与软硬件协同，理解 DeepSeek 提高 AGI 成功概率的路线选择。

访谈概述

腾讯科技完整整理稿：梁文锋围绕同一套战略反复展开阐述：

DeepSeek 不准备成为下一个超级 App，而是要成为“开放、低成本、自我加速”的 AGI 基础设施公司。

核心目标函数不是短期用户数、收入或估值，而是“提高最先实现 AGI 的概率”。开源、低价、不抢应用、融资、押注 Coding Agent、适配国产芯片，看似分散，实际上都服务于这个目标。

九个关键判断

1、“战略克制”是最高原则

不追求超级 App、不抢流量红利、不把利润最大化，是因为应用层竞争会消耗研发注意力。梁文锋反复强调，应优先提高做成 AGI 的概率，而不是提前争夺利益。

2、技术路线非常集中

路线图大致是：语言模型 → 思维链 → 通用 Agent → 持续学习 → AI 自我迭代 → 具身智能

其中，持续学习被视为当前最关键的瓶颈；视频生成、3D、垂直医疗或金融 Agent 都不是现阶段主线。

3、Coding Agent 是战略起点，不只是产品

DeepSeek 优先做编程，并不是因为程序员市场最大，而是代码具有清晰反馈、可验证结果和自动迭代条件。其真正目标是让模型参与开发下一代模型，形成“AI 研发 AI”的内部飞轮。

4、模型首先服务自己

梁文锋明确表示，模型第一目标不是让外部用户觉得好用，而是让 DeepSeek 自己研发下一代模型时好用。由此看，C 端产品更像能力试验场，API 是现金流来源，内部研发效率才是核心用途。

5、真正瓶颈是算力和高质量数据

梁文锋认为，中美人才差距没有算力差距大；模型规模不是“已经足够”，而是受现有资源限制。同时，高质量数据标注昂贵、耗时，甚至需要核心研究员直接参与。

6、人才护城河不是招聘，而是团队稳定

融资的重要用途之一，是通过期权稳定核心成员。无 KPI、约一半时间自主探索、较少加班和共识决策，都是为了维持研究人员的内在动机。不过梁文锋也承认，团队扩大后必须补充正式组织架构。

7、开源是战略武器，不只是理想主义

DeepSeek 判断：权重公开并不会消除真正壁垒，因为高效部署、低成本推理、数据、基础设施和持续迭代仍很难复制。其 V3、R1 以及 DeepEP、3FS、FlashMLA 等基础设施的持续开放，也与这一说法基本一致。DeepSeek-V3、DeepSeek-R1、DeepSeek 开放基础设施

8、低价不是促销，而是竞争范式

API 只追求合理收益，不追求价格上限。低成本一方面扩大生态，另一方面能让同样算力训练更大模型。DeepSeek 的公开技术报告也显示，其竞争力高度依赖模型架构、低精度训练和软硬件协同，而不只是“少用显卡”。公开的 2.788 百万 H800 GPU 小时只是训练计算量，并不等于完整研发成本。DeepSeek-V3 技术资料、官方 API 定价

9、中国 AI 的优势将主要是系统性低成本

梁文锋判断，未来模型之间的差异主要剩下成本、时间和体验。中国未必始终最早，但可能通过工程效率、能源、芯片产能和较低利润诉求，成为全球最便宜的大规模智能供应方。

DeepSeek 背后的战略意图

1. 用开源和低价主动“商品化”模型能力

DeepSeek 在主动压低基础模型的超额利润：

  • 开源让模型能力快速扩散；

  • 低价迫使行业按单位成本竞争；

  • 不做应用，减少与互联网平台的直接冲突；

  • 阿里、腾讯、智谱等即使使用或部署 DeepSeek，也会扩大其技术影响力。

这等于把竞争规则从“谁拥有独家模型”，改成“谁能迭代得最快、训练得最省、部署得最好”。DeepSeek 恰恰把护城河放在后一层。

2. 建立一个递归增强的研发系统

Coding Agent → 持续学习 → 自我迭代，是整场交流最关键的战略线索。

DeepSeek 真正想制造的并不是某一代聊天机器人，而是一台能够帮助自己研究下一代模型的“研发机器”。一旦这个循环成立，模型研发就可能由线性的人力投入转向非线性加速。届时，今天的用户规模和应用收入都只是次要资产。

3. 融资的本质是“购买实验次数和时间”

此次融资规模约 500 亿元、梁文锋本人投入约 200 亿元以及腾讯、宁德时代等参投，已有其他媒体交叉报道，但具体条款仍未完全公开。从交流内容看，这笔钱主要解决三件事：

  • 购买算力，提高实验密度；

  • 用期权稳定核心研究团队；

  • 支撑高质量数据和国产芯片适配。

所以它更像一次“科研军备扩充”，而不是准备大规模买量或建设应用矩阵。选择利益一致、敌意较低的投资者，也是在尽量降低外部资本对技术路线的干扰。

4. 从 CUDA 依赖中获得战略自主性

DeepSeek 不只是适配国产卡，而是在编译器、通信库、算子和文件系统层面建设自己的技术栈。其深层意图是：

  • 降低对单一芯片和 CUDA 生态的依赖；

  • 让模型可以在多种硬件上低成本运行；

  • 参与定义国产算力的真实工作负载和软件标准；

  • 换取更稳定的长期算力供给。

如果成功，DeepSeek 不只是国产芯片的客户，还可能成为国产 AI 计算生态的“需求定义者”。

5. 保持基础设施中立，借别人的渠道完成分发

不做超级 App、不与互联网平台为敌，意味着 DeepSeek 可以同时服务多个平台。平台负责用户、场景和分发，DeepSeek负责底层智能，最终可能形成这样的定位：

上层让腾讯、阿里、京东以及创业公司竞争应用；DeepSeek 位于下层，提供开放模型、低价 API、研发工具链和硬件适配。

这比亲自经营所有应用更聚焦，也更符合其团队规模和算力约束。
