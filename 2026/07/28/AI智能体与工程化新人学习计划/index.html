AI 智能体与工程化新人学习计划

发表于 2026-07-28 分类于 Self-Learning
从 LLM API、Tool Use 和 Agent Harness 入门，逐步掌握规格驱动开发、工程循环与确定性验证。

这是一份面向工程新人的渐进式学习路线：从理解 LLM 与工具调用开始，最终独立完成一个有需求、状态、权限、验证和停止条件的本地 AI Agent。

1. 学习目标

完成本计划后，你应当能够：

  • 解释 LLM、Tool Use、AI Agent、Agent Harness、SDD 和 Loop Engineering 的区别与联系；
  • 使用 Claude API 完成基础消息调用，并理解多轮消息、Token、上下文窗口和停止原因；
  • 使用 Claude Code 阅读、修改、测试和验证项目代码；
  • 正确使用 CLAUDE.md、Agent Skills、Hooks、权限和 sandbox；
  • 使用 Spec Kit 把模糊需求转化为 spec.md、plan.md 和 tasks.md；
  • 运行 Requirements、Design、Implementation、Convergence 四个有界工程循环；
  • 使用测试、静态检查、运行结果和证据文件判断工作是否真正完成；
  • 区分普通项目内操作、需要人工审批的操作和禁止操作；
  • 独立完成一个有需求、有工具、有状态、有验证、有停止条件的本地 AI Agent。

2. 核心知识地图

关键术语

术语 简要定义
LLM 调用 将结构化消息发送给模型，并获得下一条模型输出
Tool Use 模型产生结构化工具请求，由应用或服务实际执行
Agent 能够在循环中自主选择行动、使用工具并根据结果调整的系统
Workflow 主要由程序预先确定执行路径的 LLM 工作流
Agent Harness 围绕模型构建的上下文、工具、状态、权限、执行、观测和验证系统
Prompt Engineering 优化传给模型的指令表达
Context Engineering 优化模型在当前步骤能够看到的信息
SDD 以可执行规格和明确意图驱动设计、任务、实现与验证
Loop Engineering 为 Agent 设计有评价、有预算、有停止条件的反馈循环
Eval 使用任务、测试、评分器和环境结果衡量 Agent 的真实表现

主仓库：

  • SpecKit-LoopEngineering

开始学习前，应了解以下文件：

文件或目录 学习重点
README.md 安装、初始化、安全模式和基本使用方法
CLAUDE.md 稳定工程规则及 Four-Loop 使用顺序
PROJECT-CONSTITUTION.md 意图、证据、权限和治理原则
skills/speckit-*/SKILL.md Spec Kit 的规格、计划、任务、分析和实现流程

runtime/loopctl.py.md 确定性检查、循环状态记录和升级逻辑
runtime/security_guard.py.md 文件边界、高风险命令和审批策略
install.sh / install.ps1 跨平台安装、备份、更新和诊断

4. 必修课程清单

A. Claude Code

    • 建议时间：1.5 小时
    • 学习重点：Agent Loop、上下文、Plan Mode、CLAUDE.md、Skills、MCP、Hooks。
    • 建议时间：20 分钟
    • 学习重点：安装、启动、代码探索、修改和验证。
    • 建议时间：30 分钟
    • 学习重点：探索、计划、实现、验证和上下文管理。
    • 建议时间：30 分钟
    • 学习重点：SKILL.md、触发条件、渐进式加载、脚本和团队共享。

B. LLM API 与 Agent 基础

    • 建议时间：1 小时
    • 学习重点：API 请求、模型选择、Tool Use、Agent Loop 和上下文管理。
    • 建议时间：20 分钟
    • 学习重点：messages、role、content、max_tokens、stop_reason。
    • 建议时间：40 分钟
    • 学习重点：Workflow 与 Agent、Routing、Parallelization、Evaluator–Optimizer。

C. Spec-Driven Development

    • 建议时间：40 分钟
    • 学习重点：Constitution、Specify、Plan、Tasks、Implement。
    • 学习重点：完整 SDD 工作流及各阶段产物。
    • 建议时间：1 小时 16 分钟
    • 学习重点：规格、项目宪法、计划、验证和 Agent Skills。

D. Harness、Evals 与 Loop Engineering

    • 建议时间：45 分钟
    • 学习重点：Task、Trial、Grader、Trajectory、Outcome、Evaluation Harness。
    • 建议时间：30 分钟
    • 学习重点：跨会话状态、增量工作、初始化 Agent 和持久化进度。
    • 建议时间：25 分钟
    • 学习重点：文件系统隔离、网络隔离和最小权限。
    • 建议时间：20 分钟
    • 学习重点：Agent 循环、反馈、验证和停止条件。

5. 选修课程

    • 约 8.1 小时；适合需要开发 AI 产品或后端服务的员工。
    • 约 7 小时 45 分钟；覆盖 Reflection、Tool Use、Planning 和 Multi-Agent。
    • 免费开源，提供简体中文。
    • 约 10 小时；重点是生产环境中的 Agent 故障与可靠性。
